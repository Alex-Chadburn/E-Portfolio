Embedded Systems Project

In my initial code review, I suspected asynchronous behavior and sleep timing were causing the issue. Further investigation showed that the actual cause was incorrect indentation affecting control flow. I corrected the indentation and tested the change on a Raspberry Pi.

I also simplified iteration using enumerate, removed irrelevant comments, and removed the debug flag. These changes made the code and its control flow easier to follow.

C++ Banking Program

The program continues to accept and validate financial information, including the interest rate, monthly deposit, and initial deposit, and calculate investment growth. I extended it so users can save account details to a database and retrieve them later. When an account is checked, the program recalculates its growth to reflect elapsed time.

I organized the project into separate folders for dependencies, include files, and source files. I used the C++ chrono library and date parsing to work with elapsed time.

The program can be compiled with Microsoft’s C++ compiler using:

cl /EHsc /std:c++20 /I includes /I dependencies src\main.cpp src\account_input.cpp src\banking.cpp src\database.cpp src\database_menu.cpp dependencies\sqlite3.c /Fe:Banking.exe
